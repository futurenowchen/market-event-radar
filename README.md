# Market Event Radar

A free, official-source-first financial event radar for developers and investors.

This repository is being extracted from the event-radar engine that powers the Negentropic Ataraxia investment dashboard. The goal is to provide a public, reusable JSON feed and an open-source Python backend for high-impact macro, central-bank, and major company events.

Initial public feed target: `data/latest.json`.
